# 圣诞树信件展示设计

信件正文由作者单独填写，通常为一至两段。展开时，圣诞树移到左侧，粒子直接在右侧夜空中聚成文字。阅读时，这片夜空上只呈现正文和「收起」。收起后，树回到中央，右上角留下一枚可以再次点开的信封。

## 交互流程

1. **开场时**，主景居中，祝福语在下方。主题物件位于主景右下缘、略高于祝福语的位置。主题色柔光和一圈缓慢呼吸的细光勾出入口，点物件或周围的光晕都能开信。开启「减少动态效果」时光晕常亮。
2. **点击主题物件后**，主景向左移动，物件化成粒子，旋到右侧正文首行的上方。《玫瑰星愿》在爱心开场时就能直接开信，爱心在左移途中聚成圣诞树。
3. **旋风从上往下逐字生成正文。** 旋风约一行字高，前缘略微倾斜。同一行里的字从左到右紧接着成形，扫过的文字随即稳定下来。一两段正文从首字出现到末字成形约需 2 秒。生成途中点一下正文或右侧空白，旋风会加速，剩余文字在约半秒内按原顺序写完。
4. **最后一个字成形后**，「收起」才出现在末行下方靠右的位置。点击后，末行先散开，旋风从下往上把文字卷回粒子流，越接近右上角，粒子流收得越细，最终在「重播」按钮左侧聚成细线信封。圣诞树同步归中。《玫瑰星愿》此时以树形居中，仍可点树切回爱心。
5. **收好后可以点信封重读。** 信封保留主题微光，旁边的播放控件淡出后仍然可见。点开时，信封自身散成粒子，旋到首行上方，再从上往下写出正文，圣诞树同时左移。

**重播**会从该主题原有的开场重新播放，开信入口也恢复成最初的花苞、冰晶或提灯。

**暂停与继续**同时作用于树和信件动画。写到一半暂停，继续时从刚才那个字接着写。收起途中暂停，继续时粒子从停住的位置接着向信封汇拢。

## 三款主题的粒子动效

三款共用自上而下成字、自下而上收起的路径。物件决定旋风由什么组成，也决定最后几颗粒子如何拼出同一个信封轮廓。

### 玫瑰星愿

- **展开时**，轻轻舒展的玫瑰花苞散成花瓣旋风。外圈几片较大的花瓣随风翻转，带出旋风向下掠过的走势。内圈的细碎花瓣经过每个字的位置时，顺势聚成笔画。
- **收起时**，笔画从末行起重新散成细小花瓣，沿弧线向右上方回卷。细碎粒子先勾出信封外框，最后两片花瓣从左右上角向中间合拢，画出封口的两条斜线。

### 冰晶回旋

- **展开时**，缓慢转动的六瓣冰晶旋散成一股雪旋风。外缘的晶片翻转时闪出明亮的切面，内侧细晶沿途贴着笔画迅速结霜。旋风一过，字形就清晰可读。
- **收起时**，文字碎成晶片，随反向旋风向上汇拢。四颗亮晶先定住信封的四角，细霜再从角上沿外框和封口折线生长，直至接合。

### 平安夜灯火

- **展开时**，透着暖光的小提灯化成一股暖金色的火星旋风。旋风向下扫过字位，笔画上的光点像枝头灯串一样接连亮起，随后连成稳定、柔和的文字。
- **收起时**，笔画从末行开始依次化回余火，火星连成一串向右上方飞去。领头的火星绕出信封外框，再沿封口折线走到中央，轻轻一亮后留下微光。

## 竖屏布局

- **树完整留在左下方**，左移时同步缩小，占屏宽约三分之一。最宽的枝梢与正文之间留出一段夜空。
- **正文在右侧左对齐**，保留作者输入的换行和空行，较长的句子到右边缘自然折行。先按全文排好位置，让整块文字的中心略高于屏幕中央，再由粒子逐字显现。只有两句时，文字落在画面中段。写到两段时，首行自然靠上一些。生成过程中，已经读到的行始终停在原处。
- **以 390 像素宽的手机为例**，正文从屏宽约 38% 处起排，右侧留约 18 像素。字号取 17 像素时，每行约能排 13 个汉字。
- **底部祝福语**在树左移时逐渐淡出，让读者的视线落在正文上。收起时，祝福语随树归中重新亮起。
